# Crédits des images

- **Soleil, Mercure, Vénus, Mars, Jupiter, Lune** : Solar System Scope (https://www.solarsystemscope.com/textures/),
  licence Creative Commons Attribution 4.0 (CC BY 4.0), d'après les données de la NASA. Fichiers
  `assets/textures/2k_*.jpg`, récupérés sur Wikimedia Commons le 14/10/2026. Crédit affiché dans le manuel (Notes de bord).
- **Terre** (surface, lumières de nuit, nuages, océans) : NASA (Blue Marble, Black Marble), fournies avec three.js
  (examples/textures/planets), fichiers `assets/textures/earth_*`.
- **Voie lactée** : « The Milky Way panorama », ESO/S. Brunier (https://www.eso.org/public/images/eso0932a/), licence
  CC BY 4.0, version 1280 × 640 (`assets/textures/voie_lactee_eso0932a.jpg`), récupérée le 15/10/2026. Crédit affiché
  dans le manuel (Notes de bord).
- **Saturne et ses anneaux, Uranus, Neptune, satellites** : peints par le jeu (`src/interface/vue3d/astres.ts`).
- Cartes « ligne claire » d'origine : `terre_lc.jpg`, `lune_lc.jpg` (plus utilisées dans la vue 3D).
